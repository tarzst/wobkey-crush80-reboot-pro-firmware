# WOBKEY Crush 80 Reboot Pro RGB — исправление macOS/VIA

Репозиторий содержит воспроизводимый патч официальной RGB-прошивки WOBLAB от
2026-06-18. Он исправляет работу VIA-слоёв в macOS и сохраняет официальный код
USB, OTA, VIA и RGB.

Штатная прошивка хранит четыре слоя, но реально использует 0/1. В Mac-режиме
она после чтения keymap накладывает жёсткую трансляцию модификаторов и F-ряда,
поэтому назначения VIA на слоях 2/3 игнорируются.

Патч:

- использует слои 0/1 для Windows и 2/3 для macOS;
- отключает скрытую трансляцию клавиш;
- сохраняет официальный рабочий `DYNAMIC_KEYMAP_SET_BUFFER` (`0x13`);
- не меняет boot, USB initialization, OTA, transport и RGB.

Аппаратно проверены OTA, повторная USB-enumeration, CRC, загрузка layout через
VIA, переключение Win/Mac, пользовательские бинды F-ряда и сохранение wired RGB.

Команды сборки, тестирования и прошивки приведены в [README.md](README.md).
Точные смещения и результаты находятся в [техническом отчёте](docs/TECHNICAL.ru.md).

## NativeHeld preview — 2026-10-21

Собран и проверен на одной Crush 80 Reboot Pro RGB образ с нативными
сочетаниями `QK_MODS`: модификаторы и клавиша удерживаются до отпускания
физической кнопки. `KC_TRNS` на дополнительном слое наследует назначение
парного базового слоя. Общие модификаторы и usages учитываются по владельцам.
Это дополнение к RC2, а не полный порт QMK.

- Файл: `firmware/patched/Crush80-RGB-0108-NativeHeld-20261021.bin`
- SHA-256: `7d154c51564138a5e2307d5da40b66a432452628b826592a73795d078ed49e35`
- OTA CRC: `350ad5c5`

Пользователь подтвердил удержания на Mac по USB, работу VIA, макросов, Fn-слоёв,
печать по BLE и сохранность раскладки после переподключения. Исходники C/assembly,
фиксированное размещение и сборщик опубликованы в `src/nativeheld/` и
`src/build_nativeheld.py`. Сборка из репозитория воспроизводит точный проверенный
хеш. Подробности и границы проверки — в [NATIVEHELD.md](docs/NATIVEHELD.md).

Это экспериментальная версия. В ней остаётся гонка штатного USB-отправителя,
воспроизведённая в эмуляторе: прерывание при отправке может привести к потере
обновления отчёта, включая отпускание. На железе пользователь её не наблюдал.
Не проверены нативные сочетания по BLE/2.4 ГГц и все варианты сна/вложенных IRQ.
Прошивка сбрасывает настройки; заранее сохраните layout, макросы и RGB.

[План разработки](docs/VIA-ROADMAP.ru.md) сохранён как история требований и
дальнейших задач. Поддержка `QK_MODS`/`KC_TRNS` относится к NativeHeld;
предыдущий RC2 остаётся в репозитории.

Известный заводской дефект: effect ID 11 после холодного запуска визуально
становится effect 2, хотя VIA продолжает читать сохранённый ID 11. RGB startup
в патче намеренно не изменяется; effect 11 следует избегать.
